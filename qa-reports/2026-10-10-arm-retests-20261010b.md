### 49.1 / 49.3 — `$PROFILE` に触らずに押せた

前回は「OSC 133 を出す prompt が `$PROFILE` に要る」として飛ばしたが、TESTING.md 49 節の `prompt` 関数は**ペインに読み込ませるだけで足りる**。
scratch に `osc-prompt.ps1`（関数 1 つ）を置き、`FILER_TERM_ARGS=-NoProfile` のペインで `. $env:TEMP\osc-prompt.ps1` を打った。`$PROFILE` は触っていない。
（関数をペインに直接打つ手は、入力が継続行 `>>` のまま閉じず失敗した（原因は調べていない）。ファイルにして読み込むと通る。）

- `.pty.log` に `\e]133;A` が 5 回。OSC 133 を出さない `-NoProfile` だけのときは、同じ `<C-S-Up>` が `The shell does not mark its prompts (OSC 133), so there is none to jump to`（`r491` の b〜e）。
- **49.1**: `dir`、`echo hi`、`Get-Date`、`Get-Item nothing-here` のあと。`<C-S-Up>` 1 回目で `pane back` 0→6、`dir` の prompt が表示の一番上（`r491b/m.png`）。2 回目はそのまま 6 で、トースト `No prompt above this one`。`<C-S-Down>` で 0 に戻る。
  行の書き方（`echo hi` → `dir` → `echo hi`）は、この高さ（12 行）だと 1 つ目の `echo hi` が既に画面内にあり、画面の一番上より上にある prompt は `dir` だけなので、`dir` で止まる。同じ動きの範囲（一番上に prompt が来る、無ければトースト）は成り立つ。所見 1。
- **49.3**: `<C-S-l>` でトースト `Copied the last command's output (1 line)`。`Get-Clipboard` は `Get-Item: パス '…\nothing-here' は存在しないため、見つかりません。` の 1 行だけ（prompt の行も、コマンドの行も、末尾の空行も無い）。
  行は `dir` の一覧を見るが、今回は最後に走ったのが `Get-Item` だったので、それの出力だった（「最後に終わったコマンドの出力」で一致）。`dir` 単独で押し直したい人は所見 1 を読む。

## 所見

1. **TESTING.md 49.1 は pane の高さで答えが変わる。** `echo hi` → `dir` → `echo hi` の順は、表示の一番上より上に `echo hi` の prompt があるだけの履歴が要る。
   12 行のペインで履歴が 20 行しかないと `dir` で止まる。行に「`dir` の出力が長い（`dir C:\Windows\System32` など）」か「ペインの高さ」を書くとよい。動きの退行ではない。
2. **49.1 / 49.3 は `$PROFILE` 無しで押せる。** 49 節の冒頭にペインへ貼る手（`osc-prompt.ps1` を読み込む）を書くと、`$PROFILE` が symlink の機械でも押せる。`--keys` では関数を直接打つと `"` が落ちる（所見のとおり）。

### Proposals

1. **TESTING.md 49 節の冒頭に「`$PROFILE` に入れずにペインで試す」手を足す。** `Set-Content $env:TEMP\osc-prompt.ps1 <関数>` と `. $env:TEMP\osc-prompt.ps1`。これで ARM64 / x64 のどちらの run も 49.1 / 49.3 を押せる。
2. **49.1 の行に pane の高さを書くか、`dir` を長い出力にする。** 所見 1。
3. （#308 から続き）49.10 の分割、1.43 / 40.16 の `<C-c>` を 49.9 に寄せる。
