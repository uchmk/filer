### Proposals

1. **Don't say "on PATH" for a shell given as a full path.** What I ran into:
   `FILER_TERM_SHELL=C:\nope\x.exe` reads ``Terminal failed: `C:\nope\x.exe` was not found on PATH``.
   PATH was never searched for it; the file at that path does not exist. What should change: for a value
   with a directory in it, say ``Terminal failed: `C:\nope\x.exe` does not exist — set [term] shell to one that is``
   (and the same in `filer env`). Why: someone who typed a full path checks their `PATH` and finds nothing wrong,
   when the typo is in the path itself. Size: a branch in one message.
2. **Leave the test trees under `TEMP` cleaned up when `cargo test` ends.** What I ran into:
   after `cargo test`, the scratch held about 30 `filer-test-…-34300` folders, and filer's parent
   column in every state file listed them (`parent: filer…s-34300 | filer…l-34300 | …`).
   They go only when a later process starts more than an hour later (v0.73.70). What should change: also
   remove the current process's own `filer-test-*-<pid>` folders when the test binary exits, or have the
   `util::test_dir` callers drop their tree when they finish. Why: a run that tests in the same scratch reads
   that noise in every `<State:>`, and the RAM disk fills with it across runs. Size: a function. Q-worthy only
   if keeping trees for a failed test matters (they could be kept only on a panic).

### Votes

- **Q82: 1** (don't append on lines with `&` `|` `>` `<` `;`). I measured again on this machine (`Q82\`), with the cursor on
  `a.txt`: `;dir /b | findstr a >list.txt`. It ran as
  `launched: 36508 dir /b | findstr a >list.txt "R:\…\tq82\a.txt"`, so the path became `findstr`'s
  file argument. `findstr` then read `a.txt` instead of the pipe, and `list.txt` holds `a` (the file's
  content), not the `a.txt` the listing would have given. Nothing fails or warns; the output is just quietly
  wrong. #270's `;echo hello >out.txt` put the path inside the redirected text. Writing `%*` keeps the old
  behaviour for anyone who wants it.
- **Q83: 3** (keep it to clicks). On this machine #270 reached the config folder with one
  `<F1><Click:0.29,0.227>`, the position read off the help's own `<Shot:>`. The result was
  `cwd: C:\Users\yuu06\AppData\Roaming\filer`, `overlay: none`. That replaces the 180 lines of P/Invoke
  #163 needed, so runs can already measure those lines, and a second cursor in help is not worth adding.
