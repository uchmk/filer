## Findings worth a look

1. `has_default_app` should use `ASSOCF_INIT_IGNOREUNKNOWN` (16.13).
2. The TESTING.md prompt snippet for section 49 reads `$?` after the first statement, so `$?` is always true and 49.4 shows
   only green bars. Reading `$?` first gives green and red (`k494` vs `k494b`).
3. A plain space in `--keys` is refused (`<Space>` is needed); `<C-u>` does not clear the `E` prompt, `<Tab>` cycles the
   format.

### Proposals

1. Use `ASSOCF_INIT_IGNOREUNKNOWN` in `has_default_app` (`src/exec.rs`), with a `#[cfg(windows)]` test on an unregistered
   extension.
2. Fix the section 49 prompt snippet in TESTING.md (`$c = if ($?) { 0 } else { 1 }` as the first statement).
3. Add a `<Click:x,y,mods>` form (or `<CClick:>`) to `--keys` so 49.5-49.7 can run unattended.
