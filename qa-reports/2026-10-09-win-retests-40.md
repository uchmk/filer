### Proposals

1. Use `ASSOCF_INIT_IGNOREUNKNOWN` in `has_default_app` (`src/exec.rs:711`), with a `#[cfg(windows)]` test on an unregistered
   extension (a line; the same as win-retests-39's proposal 1).
2. Give `open_default` the line note too: `Opened doc.docx with the system's default app (line 3 not passed: this opener takes no
   line)`, or word 16.3b as "with an opener that is `start "" %*`". Today the same outline `<Enter>` says different things
   depending on whether `yazi.toml` has an `[opener]` (a line).
3. Add a modifier form to `--keys`' pointer tokens (`<Click:0.5,0.4,C>` or `<CClick:…>`), and a `<Hover:…>` that holds the
   pointer over a place for N ms. 49.5-49.7 and the "pointer turns into" half of 1.44 cannot run unattended without them;
   this run needed `SetCursorPos` / `GetCursorInfo` outside `--keys` for 1.44 and could not make the Ctrl half work for 49.6
   (a function).
4. `<State:>` could print the cursor shape the window last asked for (`cursor: ns-resize`), so 1.44's pointer half and 49.5's
   hand are text rows instead of an external `GetCursorInfo` script (a line or two in `main.rs`).
5. Make 33.7's toast not cover the preview: shorten to the last two path segments or let the toast be a single row
   (`Config: …\yazi.toml: TOML parse error — the rest in ~`). The row is read as text and held; the cost is on the owner's
