## How the rows were pressed

Registering with `claude mcp add` writes the owner's Claude Code config, and `/mcp` is an interactive screen. Instead each Claude run used
**`claude -p … --mcp-config <scratch>\mcp.json --strict-mcp-config --no-session-persistence --output-format stream-json --verbose`** with a
config naming `filer.exe mcp` (or `filer.com mcp`) -- the same server process, started by the same Claude Code. The `system/init` event of that
stream lists `mcp_servers` with the status `/mcp` shows, and the tools it loaded. `--allowedTools` allowed only the filer tool under test.
Windows were driven by `--keys` with long `<Wait:50000>` pauses (a wait is capped at 60000: `<Wait:120000>` is `keys: refused`, run `b`).
A plain JSON-RPC client (`mcpcall.ps1`, over stdio) was used beside Claude to read the raw answers.
